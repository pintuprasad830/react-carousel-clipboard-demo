# React Carousel and Clipboard Demo

This repository contains two React mini projects.

## 1. Carousel Demo
Features:
- Axios API call
- Auto slideshow
- Manual next/previous buttons
- useEffect
- useRef
- setInterval

## 2. Clipboard Demo
Features:
- Copy detection
- Paste blocking
- onCopy event
- onPaste event
- onBlur event

## Technologies Used
- React JS
- Bootstrap
- Axios
- JavaScript
